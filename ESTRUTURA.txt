ESTRUTURA DO PROJETO - DevFlow (React + Tailwind)
==================================================

devflow/
├── public/
│   └── index.html
├── src/
│   ├── App.jsx                    ← Arquivo principal (composição)
│   ├── main.jsx                   ← Entry point do React
│   ├── index.css                  ← Tailwind imports
│   ├── components/
│   │   ├── Sidebar.jsx            ← Menu lateral com subitens
│   │   ├── Topbar.jsx             ← Barra superior com breadcrumb
│   │   ├── BibliotecaTab.jsx      ← Aba Biblioteca de Componentes
│   │   ├── LicoesTab.jsx          ← Aba Lições Aprendidas
│   │   ├── SugestoesTab.jsx       ← Aba Sugestões Inteligentes
│   │   ├── ComponentCard.jsx      ← Card individual de componente
│   │   ├── ComponentDetail.jsx    ← Tela de detalhe do componente
│   │   ├── StatsBar.jsx           ← Barra de estatísticas
│   │   ├── StarRating.jsx         ← Componente de avaliação
│   │   └── PlaceholderPage.jsx    ← Página placeholder (módulos futuros)
│   ├── data/
│   │   └── mockData.js            ← Dados mockados (componentes, lições)
│   └── icons/
│       └── SidebarIcons.jsx       ← Ícones SVG da sidebar
├── package.json
├── tailwind.config.js
├── postcss.config.js
└── vite.config.js

COMO RODAR:
1. npm install
2. npm run dev

ONDE COLOCAR CADA CÓDIGO:
- Cada arquivo .jsx vai na pasta indicada acima
- O App.jsx só importa e compõe os componentes
- Os dados ficam centralizados em data/mockData.js
- Os ícones SVG ficam em icons/SidebarIcons.jsx
